Four-modality, ten-recording subject-disjoint matrix (WiFi, PWR, UWB, Kinect).

`v7/` is the archived source; `v7r1/` was rebuilt using `fix_operanet_v7r1.sh` and passed its source-level identity/room checks. The final original v7r1 files and per-seed JSON were not exported from OMNI. Some MAT input requires `matio.load_from_mat` as used in the original project; that module was not part of the archives.

The classification split is **not** an unseen-room evaluation.
